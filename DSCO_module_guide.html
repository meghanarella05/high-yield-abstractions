DSCO (CES 2104) – Module Guide

Each module = core abstraction → derive the algorithm → worked examples (Q# = your model-answers file) → check. Read the abstraction, then rewrite the derivation from memory 3×.

M1 · Minimization (K-map, PI/EPI, NAND/NOR) · Q1–7
Core abstractionA function is a set of minterms. Two minterms differing in 1 bit merge and the changing variable disappears. K-map = a picture where "differ by 1 bit" = physically adjacent (wraps around).
Derive
  1. Group 1s in powers of 2 (1,2,4,8), as big as possible, wrap edges.
  2. Variable that stays constant stays; the one that changes vanishes. 1 = plain, 0 = primed.
  3. EPI = group covering a minterm no other group covers → mark it first, then cover leftovers with fewest groups.
  4. Don't-care: use as 1 only if it enlarges a group, else 0.
  5. POS: group the 0s → F' → De Morgan (flip every literal, swap AND/OR).
  6. SOP → NAND-NAND (same expression, every gate NAND). POS → NOR-NOR.
ExamplesQ1 Σm(0,1,2,5,8,9,10): B'C' + B'D' + A'C'D, all 3 are EPI (m9, m2/m10, m5 unique).
Q2 Σm(1,3,7,11,15)+d(0,2,5): A'B' + CD (d5 unused).
Q4 POS of Q1: (B'+D)(C'+D')(A'+B').
Q5 AB+CD = NAND(NAND(A,B),NAND(C,D)).
Q6 NAND universal: NOT = NAND(A,A); AND = NOT after NAND; OR = NAND(A',B').
CheckEvery 1 covered? Group sizes powers of 2? Any group still enlargeable (then not prime)? Spot-check one minterm by substituting.
M2 · Arithmetic circuits (adders, comparator, multiplier) · Q8–13
Core abstractionAdding bits = XOR (sum) + AND/majority (carry). Wider arithmetic = the same cell repeated, with carry wired stage to stage.
Derive
  1. HA: S = A⊕B, C = AB.
  2. FA: S = A⊕B⊕Cin, Cout = AB + Cin(A⊕B) = two HAs + OR on carries.
  3. Ripple n-bit: Cout(i) → Cin(i+1); delay ≈ n × carry delay. Fix: look-ahead, Gi = AiBi, Pi = Ai⊕Bi, C(i+1) = Gi + PiCi.
  4. Add/Sub: B' = B⊕M, Cin = M (M=1 gives A + B' + 1 = A−B). Signed overflow V = C4⊕C3.
  5. BCD: binary add, then if sum > 9 or carry add 0110. C = K + Z3Z2 + Z3Z1.
  6. Comparator: xi = XNOR(Ai,Bi); scan from MSB, first unequal bit decides. A>B = A3B3' + x3A2B2' + x3x2A1B1' + …
  7. 4×4 multiplier: 16 ANDs for ai·bj, shift rows, add with ~4 HA + 8 FA; output P7..P0.
ExamplesQ11 8+5: 1000+0101 = 1101 → Z3Z2=1 → +0110 = 1 0011 → BCD "13".
Q8 FA truth: S=1 for 001,010,100,111; Cout=1 for 011,101,110,111.
CheckPlug A=1,B=1,Cin=1 → S=1, Cout=1. Why 6 in BCD? 16 codes minus 10 used.
M3 · MUX / Decoder / Encoder as function generators · Q15–20
Core abstractionMUX = selects one input by address. Decoder = generates every minterm (one-hot). Encoder = reverse of decoder. So any function = a MUX with chosen data inputs, or a decoder + OR of its minterms.
Derive
  1. n-variable F on a 2^(n−1):1 MUX: first n−1 variables are selects, last variable (C) is data.
  2. For each select combo look at the minterm pair: (0,0)→0, (1,1)→1, (0,1)→C, (1,0)→C'. That is the data input.
  3. Decoder + OR: write Σm list, OR those outputs (NAND if outputs are active-low).
  4. Bigger from smaller: decoder → top bit drives enables (A3' to first, A3 to second). MUX 16:1 = 4 MUX at level 1 (S1S0) + 1 at level 2 (S3S2).
  5. Encoder: Yk = OR of inputs whose index has bit k set. Priority encoder: higher input masks lower (X don't care), add valid V = OR of all.
ExamplesQ16 F=Σm(1,2,6,7), S1=A, S0=B: I0=C, I1=C', I2=0, I3=1.
Q19 Full adder on 3:8: S = Y1+Y2+Y4+Y7, Cout = Y3+Y5+Y6+Y7.
Q20 4:2 encoder Y1 = D2+D3, Y0 = D1+D3; priority: Y1 = D3+D2, Y0 = D3+D2'D1.
CheckTest one select combination by hand, compare to truth table.
M4 · Verilog (combinational vs clocked) · Q14, 21–24, 39–42
Core abstractionVerilog describes hardware, not a program. Two kinds only: combinational (output follows inputs) and clocked (state changes at an edge). wire = connection, reg = assigned inside always.
Derive (template choice)
  1. Simple equation → assign y = ...;
  2. Combinational with if/case → always @(*), use =, assign every output in every branch (else a latch appears).
  3. Flip-flop/register/counter/FSM state → always @(posedge clk), use <=. Async reset: add or posedge rst to the list.
  4. Big circuit from small → structural: instantiate modules, internal nets as wires.
  5. FSM = 3 parts: state register (clocked), next-state logic (case), output logic.
Examples
// Q14 behavioural adder
assign {cout, s} = a + b + cin;
// Q39 async-clear D FF
always @(posedge clk or posedge clr)
  if (clr) Q <= 0; else Q <= D;
// Q41 shift reg
else Q <= {Q[2:0], din};
// Q42 FSM next-state
S3: begin next = x ? S1 : S2; z = x; end
Q21 4:1 MUX with if-else and case; Q22 2:4 decoder: Y=0 default, then case(A) if E. Q40: q1<=d; q2<=q1; is 2-stage shift; with = it collapses.
CheckMissing else/default (latch)? = in clocked block? reg driven by assign? Port widths match?
M5 · Memory elements: latch → flip-flop → conversions · Q25–29
Core abstractionMemory = feedback loop. Latch is level-sensitive (transparent while enable is on); flip-flop is edge-triggered (two latches, master-slave). Combinational = no state, sequential = state.
Derive
  1. SR (NOR): 00 hold, 10 set, 01 reset, 11 invalid. NAND version is active-low.
  2. Remove invalid: D latch, S = D, R = D'.
  3. JK = SR where 11 toggles. Race-around: J=K=1 with level clock toggles repeatedly. Cure: master-slave or edge trigger.
  4. Characteristic equations: D: Q+ = D; T: Q+ = T⊕Q; JK: Q+ = JQ' + K'Q; SR: Q+ = S + R'Q.
  5. Conversion: write excitation table of the given FF, express its inputs in terms of the wanted input and Q (K-map if needed).
ExamplesQ29 JK excitation 0→0: J=0,K=X; 0→1: 1,X; 1→0: X,1; 1→1: X,0. So JK→D: J=D, K=D'. JK→T: J=K=T. D→T: D = T⊕Q.
CheckApply every input combination to your converted FF and compare with target characteristic equation.
M6 · Registers and counters · Q30–35
Core abstractionA counter is an FSM whose state is the output. A shift register is FFs chained so each clock moves data one place. The only design question: when does each bit toggle?
Derive (synchronous counter)
  1. Write the sequence as present → next state table.
  2. For T flip-flops: T = Q ⊕ Q+ (1 where bit changes). JK: J=K=T.
  3. Unused states = don't care, K-map each T.
  4. Shortcut: up counter, bit i toggles when all lower bits are 1; down counter, when all lower bits are 0. Up/down with M: Ti = M·(lower all 1) + M'·(lower all 0).
  5. Ring: Q3→D0, preset 1000, n states. Johnson: Q3'→D0, start 0000, 2n states.
  6. Ripple: CLK to FF0 only, each next FF clocked by previous Q; delay adds up.
ExamplesQ32 3-bit up/down: T0=1, T1=M·Q0+M'·Q0', T2=M·Q1Q0+M'·Q1'Q0'.
Q33 mod-6: T0=1, T1=Q2'Q0, T2=Q0(Q1+Q2).
Q31 Johnson: 0000→1000→1100→1110→1111→0111→0011→0001.
Q35 ring from 2-bit counter + 2:4 decoder.
CheckSimulate the equations from 000 through the sequence and the two unused states (they should fall back in).
M7 · FSM design (Mealy/Moore, sequence detector) · Q36–38
Core abstractionState = how much of the pattern you have matched so far. Mealy: output on arcs (state + input). Moore: output on the state only (usually one extra state, one clock later).
Derive
  1. Word problem → state diagram: one state per matched prefix.
  2. On a mismatch go to the state of the longest suffix that still matches (this gives overlapping).
  3. State table → minimise → binary assignment.
  4. Pick FF type, excitation table (D: D = Q+).
  5. K-map the FF inputs and output → draw circuit → simulate.
ExamplesQ36 1011 Mealy overlapping: S0..S3 = 00,01,10,11. S3 on 1 → output 1, go to S1. D0 = X, D1 = Q0X' + Q1Q0'X, Z = Q1Q0X. Q42 is the Verilog of it.
CheckFeed 1011011 and confirm output 1 at the 4th and 7th bit.
M8 · Instruction set architecture · Q43–49
Core abstractionInstruction = operation + where operands live. Addressing mode = the rule that computes the effective address (EA). PC drives sequencing, branches overwrite PC.
Derive
  1. Modes: Immediate (value in instr), Register (in reg), Direct EA=LOC, Reg-indirect EA=[R], Indirect EA=[[LOC]], Index EA=X+[R], Relative EA=PC+X, Autoinc (R)+ use then add, Autodec -(R) subtract then use.
  2. Endian: word 0x12345678 at 1000. Big: 12 34 56 78. Little: 78 56 34 12.
  3. Loop program: init count, clear sum, pointer → loop body (Add (R2)+,R0 ; Decrement ; Branch>0) → store.
  4. n-address code: 3-addr one op per instr; 2-addr dest=dest op src; 1-addr via accumulator + temp; 0-addr via postfix (PUSH operands, op pops two).
  5. RISC: only Load/Store touch memory, so A+B = Load, Load, Add, Store.
ExamplesQ49 X=(A+B)×(C+D). 0-addr: PUSH A, PUSH B, ADD, PUSH C, PUSH D, ADD, MUL, POP X.
Q48 CISC: Move C,A ; Add C,B. RISC: Load R2,A ; Load R3,B ; Add R4,R2,R3 ; Store R4,C.
CheckEvery register initialised? Pointer incremented by word size (4)? Branch tests the flag you just set?
M9 · Computer arithmetic (Booth, division, IEEE 754, FP add) · Q50–55
Core abstractionMultiply = shift and add; divide = shift and subtract. Booth: a run of 1s = 2^(k+1) − 2^j, so one subtract at the start and one add at the end of the run. IEEE: number = ±1.M × 2^(E−bias).
Derive
  1. Booth: A=0, Q=multiplier, Q−1=0, M=multiplicand. Repeat n times on (Q0,Q−1): 10 → A−M; 01 → A+M; 00/11 → nothing; then arithmetic shift right A,Q,Q−1.
  2. Restoring division: A=0, Q=dividend. Repeat n: shift A,Q left; A=A−M; if A<0 → q0=0 and restore (A+M), else q0=1. Non-restoring: if A≥0 subtract else add, fix remainder at the end.
  3. IEEE single: binary → normalise 1.xxx × 2^e → sign; E = e+127 (8 bits); M = bits after the point padded to 23.
  4. FP add: align exponents (shift smaller right) → add mantissas → normalise → round.
ExamplesQ50 (+7)×(−3): M=0111, −M=1001, Q=1101 → AQ = 1110 1011 = −21.
Q52 15÷4: quotient 0011 = 3, remainder 00011 = 3.
Q53 −13.75 = 1101.11 = 1.10111×2³ → 1 10000010 1011100… = 0xC15C0000.
Q54 9.75+0.5625: shift by 4 → 1.0100101×2³ = 10.3125.
CheckBooth: n cycles, ASR keeps sign, result = M×Q by decimal. Division: dividend = divisor×Q + R.
M10 · Control unit (datapath, hardwired, microprogrammed) · Q56–63
Core abstractionControl unit = an FSM whose outputs are datapath control signals and whose inputs are status flags. Hardwired = that FSM in gates/FFs (fast, rigid). Micro-programmed = the same FSM stored in a ROM, one word per state (slower, flexible).
Derive (from an ASM chart)
  1. List datapath parts (registers, adder/sub, counter) and the control signals each needs.
  2. Draw states: idle → init → decision → action → shift/count → done.
  3. Hardwired (one-hot): D(Si) = OR of [previous state · branch condition]. Outputs = state bits.
  4. Micro: each state becomes a microinstruction = control bits + condition select + next address. µPC increments or loads branch target.
  5. Horizontal = 1 bit per signal (wide, fast). Vertical = encoded fields (narrow, slow).
ExamplesQ57 Booth controller: S2 decides on Q0Q−1 (01→S3 add, 10→S4 sub, else S5), S5 = ASR + C−1, Z=1 → S6 done. D(S3) = S2·Q0'·Q−1.
Q60 same as 7 ROM words.
Q63 single bus: fetch = PCout,MARin,Read,Add,Zin → Zout,PCin,Yin,WMFC → MDRout,IRin.
CheckEvery state has exit for every condition? Each control signal asserted in exactly the right state?
M11 · Cache and memory hierarchy · Q64–69
Core abstractionLocality (temporal, spatial) means a small fast copy of memory works. Mapping function = rule deciding which cache line a memory block may occupy.
Derive
  1. Word bits = log2(block size). Lines = cache size / block size.
  2. Direct: block(line) bits = log2(lines); tag = address − block − word. Associative: no index, tag = address − word. k-way: sets = lines/k; set bits = log2(sets).
  3. Trace: direct line = block mod lines; set-assoc set = block mod sets; evict by FIFO (oldest) or LRU (least recently used).
  4. AMAT = hit time + miss rate × miss penalty. Write-through: write both. Write-back: dirty bit, write on eviction.
ExamplesQ66 64K memory, 1K cache, 16-word block: direct Tag6|Block6|Word4; associative Tag12|Word4; 4-way Tag8|Set4|Word4.
Trace 0,8,0,6,8 on 4 blocks: direct 0 hits; 2-way LRU 1 hit.
Q67 string 7,0,1,2,0,3,0,4,2,3,0,3,2 with 3 frames: FIFO 10 misses, LRU 9.
Q68 2 + 0.05×50 = 4.5 ns.
CheckTag+index+offset = address bits. Hits + misses = accesses.
M12 · I/O and parallelism (polling, interrupt, DMA, pipeline, Flynn) · Q70–77
Core abstractionBoth topics remove waiting. I/O: polling → interrupt → DMA progressively takes the CPU out of the loop. Parallelism: overlap work (pipeline), do many data at once (vector/SIMD), or use many CPUs (MIMD, UMA/NUMA).
Derive
  1. Polling: loop read status → test ready → branch → read data. Interrupt: finish instr → save PC → ISR → return. Vectored = device supplies ISR address. DMA: CPU gives start addr + count + direction, DMA moves block, interrupts at end.
  2. Pipeline: k stages, n tasks. Non-pipe = n·k·tp. Pipe = (k+n−1)·tp. Speed-up = nk/(k+n−1) → k.
  3. Hazards: structural → duplicate hardware; data (RAW) → forwarding/stall; control → prediction/flush.
  4. Flynn: SISD, SIMD (vector/GPU), MISD (rare), MIMD (multicore). UMA same latency; NUMA local fast, remote slow.
ExamplesQ74 k=5, n=100: 104 cycles vs 500, speed-up 4.81.
Q71 polling vs interrupt table: CPU wasted vs useful work.
CheckSpeed-up must be less than k. Hazard answer names the fix.
